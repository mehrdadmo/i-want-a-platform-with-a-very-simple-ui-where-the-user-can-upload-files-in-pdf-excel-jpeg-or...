# I want a platform with a very simple UI where the user can upload files in PDF, Excel, JPEG, or...

I want a platform with a very simple UI where the user can upload files in PDF, Excel, JPEG, or PNG format.
The workflow should work like this:
The user provides two Tamin Ejtemaei lists. One can be a scanned version (image/PDF), and the other is the original/digital version. The system needs to compare and reconcile these two lists.
After that, the system should compare the reconciled Social Security list against an Excel file.
The Social Security list should be treated as the reference/source of truth. If there is an item in the Excel file that does not exist in the Social Security list, the system should identify and clearly show those items.

At the end, the system should generate a complete reconciliation report that includes:

1. An overall summary of the reconciliation process.
2. A comparison table showing the matching status between the scanned Social Security list and its original version.
3. A final comparison showing the matching status between the Social Security list and the Excel file.
4. A clear list of items that exist in the Excel file but are missing from the Social Security list.
5. Any discrepancies, missing records, or mismatched values that were identified during the process.

After reviewing and approving the results, the user should be able to export the final reconciliation results as an Excel file.

The entire reconciliation and report-generation process must be performed by ChatGPT Luna (gpt-6-luna).

The workflow should be very simple:

User uploads the files → the platform sends the files to the OpenAI API → GPT-6 Luna analyzes and reconciles the documents → GPT-6 Luna generates the report and comparison results → the platform displays the results to the user → after user approval, the user can export the results as an Excel file.

The prompt for the reconciliation process is already attached. Do not modify or rewrite the prompt. Just use it as provided and display the results generated by the model.

Also create an environment variable for the OpenAI API key so I can provide the API key and the application can use it.

The implementation should be as simple, clean, smooth, and user-friendly as possible. The UI should not be complicated. The main goal is to make the entire workflow feel seamless: upload the files, let GPT perform the reconciliation, review the results, approve them, and export the final Excel file.
